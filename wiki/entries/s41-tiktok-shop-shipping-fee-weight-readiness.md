# TikTok Shop 运费与重量结算加严就绪体检（11-12 起 × 虚高运费 × 改重降结算）

| 字段 | 内容 |
| --- | --- |
| 市场 | SaaS / 订阅 |
| 适配 | 运营 |
| 优先 | 是 |
| 更新 | 2026-11-09 |

## 一句话

帮走 TikTok Shipping（Standard Delivery / CBT / Express）的美区店，在 **2026-11-12**（太平洋时间）起平台加严「虚高运费、虚假重量、下单后改轻重量」执法之前，把 listing 重量尺寸、低价高运费、ERP 批量同步与 RTS 前后改重权限过一遍，输出「哪些 SKU 会被新结算逻辑打中 × 本周必改清单」——和 `s28`（AHR）/`s39`（API 取消×SFCR）同属旺季账户健康，但管的是**运费结算与重量诚信**。

## 为什么现在

公开二手报道（Niceggie，源标 TikTok；页面约 **2026-11-06 / 11-07**）写明：TikTok Shop 已更新运费估算与结算规则，并自 **2026-11-12 PT** 起对判定违规的店铺加严执法：

- 覆盖行为：低价商品配异常高运费、反复录入不准的包裹重量、下单后手动改轻重量以影响买家结算价、拆单规避运费等
- 覆盖物流：TikTok Shipping **Standard Delivery、CBT、Express Shipping**（不是自动打所有店，主要打平台认定违规的店）
- 新估算逻辑要点：订单创建时的预估运费**不会因事后改轻重量而下降**；重量/尺寸上调时预估运费可上调；**最终结算仍以承运商实测可计费重量为准**
- 从下单到发货、RTS 前后，平台可能用不同重量评估方式交叉核对

官方 *Fair Pricing Policy*（**2026-11-04** 更新，中文汇编见 DIGSOHO）同时要求运费按公开承运商费率、处理成本与消费者预期设上限，超限运费模板无法保存，违规可扣 AHR、移除 listing；官方 *Product Listing Policy*（Updated **2026-11-06**）也要求卖家按 Seller Center 指引提供准确的 Package Weight and Dimension——重量不准同时踩 listing 合规与结算执法两条线。跨境直发、小轻件、服饰配件、ERP 批量同步重量的店受影响更大；BFCM（11-11 起）单量一上来，结算争议与处罚会叠在一起。

这和 `s28`（AHR 扣分/里程碑）、`s39`（API 取消计 SFCR）**同属旺季健康**，但切口是**运费模板 × 重量主数据 × 改重权限**，不是违规分或取消归因。

## 目标客户

TikTok Shop US 上用 Standard / CBT / Express、有跨境直发或轻小件/配件、用 ERP/表格批量写重量、或低客单+运费占比较高的中小卖家与小代运营；以及做 TTS 物流/ERP 实施、要在 11-12 前帮客户清主数据的一人顾问。纯 FBT、几乎不自填重量的店不是首要客户。

## 一人怎么起步

两周 concierge（本周就要动，截止只剩几天）：公开自查表问「Standard/CBT/Express 各占多少？有没有低价高运费模板？重量是手工还是 ERP 同步？下单后谁能改重量？」→ 对 5–10 个报名店：导出或抽检高销 SKU 的填写重量 vs 实秤/纸箱尺寸（计体积重）；标出虚高运费、长期偏轻、可被改重的流程；关掉或收紧 RTS 前改重权限；按承运商可计费口径改 ERP 与 listing；交付「SKU 风险表 + 本周必改 + 结算对账怎么看」分数卡。先收一次性就绪体检费；代运营可加「重量漂移周报」订阅。

## 难度

低到中（主要是抽检称重、运费模板对照与权限收口；要会读结算里的预估重量 vs 承运商计费重量，不强制写代码）

## 变现路径

一次性 TTS 运费×重量就绪体检（示意 $99–$299 / 店）；「高风险 SKU 清单 + 改重权限 SOP + 本周整改」固定价（示意 $300–$800）；之后重量/结算差异周报（示意 $49–$149 / 月）。可与 `s28`/`s39` 组成「旺季账户健康」三件套，条目分开。不承诺「改完一定不被点名」——执法名单由平台认定。

## 注意的坑

政策写的是对**认定违规店**加严，不是 11-12 起全网换公式；不要恐吓「所有店明天改价」。预估运费与最终承运商计费重量本就会有差，正常波动不等于欺诈。不要教客户「怎么改重仍不被抓」，产品是**主数据与权限整改**。FBT / 非覆盖物流方式另论。以 Seller Center 通知、结算报告与官方运费/履约文档为准；Niceggie 为二手汇编，引用时保留官方核对义务。
