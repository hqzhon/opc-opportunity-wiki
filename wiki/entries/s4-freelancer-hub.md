# 自由职业者轻量客户中枢

| 字段 | 内容 |
| --- | --- |
| 市场 | SaaS / 订阅 |
| 适配 | 偏技术 |
| 优先 | 否 |
| 更新 | 2026-10-27 |

## 一句话

只做提案、合同电签、发票收款、客户门户四件套，定价明显低于 HoneyBook 等全能套件，服务「每月发 10–20 份提案」的自由职业者。

## 为什么现在

HoneyBook 2025 年起显著涨价（公开对比文称 Starter/Essentials/Premium 月费上调幅度很大，有报道称部分档约 +80% 量级），社群里「功能过剩、只要发提案并收款」的抱怨稳定存在。2026 对比文把 Bonsai、Moxie、Dubsado、Plutio 等列为替代——说明需求真实，但也说明竞品不少。一人公司楔子是：**更狠的功能边界 + 更低价 + 更快上手**，而不是再做一个全能 CRM。

## 目标客户

月入数千美元、每月发 10–20 份提案的写手 / 设计师 / 顾问 / 婚礼与活动自由职业者。

## 一人怎么起步

两周验证：落地页收 waitlist（明确「不做项目甘特/不做复杂 CRM」）→ MVP：提案 + 电签 + Stripe 发票 + 简易客户门户 → 找 10 个从 HoneyBook/表格出走的用户 concierge 试用 → $12–$19/月。用法务模板仅作起点，标注地区差异需用户自审。

## 难度

中（功能边界要狠；电签与发票有合规细节）

## 变现路径

月订阅；可加支付手续费分成；后期可卖模板包。

## 注意的坑

功能蔓延打回全能产品；法务模板地区差异大，勿提供法律意见；HoneyBook/Bonsai 促销与降维打击；获客别只靠「更便宜」——要强调「打开就能发提案」。
