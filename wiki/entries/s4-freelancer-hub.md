# 自由职业者轻量客户中枢

| 字段 | 内容 |
| --- | --- |
| 市场 | SaaS / 订阅 |
| 适配 | 偏技术 |
| 优先 | 否 |
| 更新 | 2026-10-26 |

## 一句话

只做提案、合同电签、发票收款、客户门户四件套，定价低于全能套件。

## 为什么现在

HoneyBook 等涨价后，大量自由职业者抱怨功能过剩。「只要发提案并收款」的需求稳定。

## 目标客户

月入数千美元、每月发 10–20 份提案的写手 / 设计师 / 顾问。

## 一人怎么起步

落地页收 waitlist → MVP：提案 + 电签 + Stripe 发票 + 简易门户 → $12–$15/月。

## 难度

中（功能边界要狠）

## 变现路径

月订阅；可加支付手续费分成。

## 注意的坑

功能蔓延打回全能产品；法务模板地区差异。
