## 一句话

帮在 **英国、德国、法国、意大利、西班牙** 站做自发货（FBM），并使用 Amazon 预付退货面单（APRL）的卖家，在 **2026-12-10** 前把退货签收和索赔流程改清楚：从当天起，预付面单退货若在途遗失或在交付时被卖家拒收，Amazon 会**自动向买家退款**；由亚马逊运营的承运商遗失可走 SAFE-T 索赔，其他快递遗失须自行联系承运商、**不能向 Amazon 索赔**；拒收交付会失去索赔资格，官方建议先签收。先出一份「自动退款场景 / 可索赔 vs 不可索赔 / 签收 SOP」分数卡。不要和美国站 12-18 起必须提供预付面单的 [s27](s27-amazon-fbm-prepaid-return-label-readiness.md) 混用日期或站点。

## 为什么现在

Amazon 英国 Seller Central 官方公告（News_Amazon，《Automated refunds for lost or rejected APRL returns starts on 10 December》）写明：

- **2026-12-10** 起，当使用 Amazon Pre-paid Return Label（APRL）的退货在途遗失，或在交付时被卖家拒收，平台将自动向买家退款。适用范围是 **英国、德国、法国、意大利和西班牙** 的 FBM 订单。
- **在途遗失**：若由 Amazon 运营或代表 Amazon 运营的配送合作伙伴承运，卖家可以提交 SAFE-T（Seller Assurance for e-Commerce Transactions）索赔求偿；若由**其他快递**承运，卖家须直接联系该快递，因为这类退货**不具备向 Amazon 求偿的资格**。
- **交付时拒收**：平台会自动向买家退款，卖家不必再手动处理该笔退款或回复买家相关联系。官方建议**改为签收**，以保留求偿资格；若退货到达时损坏、与描述明显不符或涉嫌欺诈，可在 **60 天内**提交 SAFE-T 索赔。
- 卖家也可以设置 returnless resolutions（免退退款规则），按条件或单个 SKU 适用。
- 官方写明卖家**不必额外操作**，自动退款届时生效；可通过 Seller-fulfilled return reports 查看退款记录。详情指向帮助文 *Reimbursements for seller-fulfilled orders with Amazon pre-paid return labels*（本轮未在未登录状态下抓到该帮助页正文，细则以 Seller Central 内帮助文为准）。

这和美国站 [s27](s27-amazon-fbm-prepaid-return-label-readiness.md) 不是同一件事：s27 是 **12-18** 起 US FBM **必须**在 7 天内上传预付面单或免退退款，否则平台可能自动扣款；本条是英德法意西站 **12-10** 起，对已经使用 APRL 的遗失 / 拒收退货自动退买家，并改写了索赔路径。欧洲与英国站假日退货窗见 [s72](s72-amazon-eu-uk-holiday-returns-readiness.md)。

## 目标客户

在英、德、法、意、西站自发货占比较高、已经或即将使用 Amazon 预付退货面单的卖家，以及给这些店做客服 / VA 或处理退货签收的小团队。尤其常拒收破损件、退货走非亚马逊快递、或还没有免退规则的店。只做美国站 FBM 的，先看 [s27](s27-amazon-fbm-prepaid-return-label-readiness.md)；只做 FBA 的，不是首要客户。

## 一人怎么起步

两周 concierge（12-10 前完成）：确认客户是否在英德法意西站用 APRL；拉近 90 天卖方履行退货报告，标出承运商是不是 Amazon 运营的配送合作伙伴、历史上有没有拒收退货、有没有已设免退规则。交付一页 SOP：默认签收、何种情况 60 天内提 SAFE-T、非亚马逊快递遗失如何向承运商索赔并保留面单和追踪记录、哪些 SKU 适合先设免退。只出书面流程和检查点，不代登录 Seller Central 提索赔，也不保证 SAFE-T 或快递索赔一定成功。先收一次性体检费；12-10 后对照自动退款报告做巡检的，另报。

## 难度

低（官方公告已写明日期、五站范围和「亚马逊承运可索赔 / 其他快递不可向平台索赔 / 拒收会失去资格」；费功夫的是帮店里分清每票退货的承运商和签收习惯）

## 变现路径

一次性英德法意西 FBM APRL 自动退款流程体检（示意 $99–$249 / 店，含承运商分流和签收 SOP）；12 月退货高峰期的退款与索赔对照巡检（示意 $49–$99 / 月）。不包代提 SAFE-T 或与快递交涉。

## 注意的坑

不要把本条写进美国站，也不要和 [s27](s27-amazon-fbm-prepaid-return-label-readiness.md) 的 12-18、7 天时钟混用。官方写的是英德法意西五站，不要自行推广到欧洲其他站或北美站。官方说「不必额外操作」指自动退款会生效，不代表卖家没有流程要改：拒收交付会触发自动退买家并可能失去求偿资格。非亚马逊快递的在途遗失不能向 Amazon 索赔，不要承诺平台会赔。SAFE-T 有 60 天窗口，且只适用于公告写明的情形，不要保证通过。本轮未抓到帮助页 *Reimbursements for seller-fulfilled orders with Amazon pre-paid return labels* 的未登录正文，金额、时限和其他例外以 Seller Central 内页为准。价格只是示意，需自行验证。
