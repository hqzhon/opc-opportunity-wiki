# 美国邮政小包 Entry Type 13 就绪体检（01-20 起 × 301 关税与 FDA/CPSC 类商品 × 缺数据被扣或退回）

| 字段 | 内容 |
| --- | --- |
| 市场 | SaaS / 订阅 |
| 适配 | 运营 |
| 优先 | 是 |
| 更新 | 2026-11-05 |

## 一句话

帮从美国境外用**邮政小包**直发美国买家的小卖家（Etsy 国际卖家、独立站直邮、跨境小包），在 **2027-01-20** 前把每个 SKU 过一遍：10 位 HTSUS 编码、原产国、申报价值、是否带 301/232/201 关税、是否属于 FDA / CPSC 等机构管辖、需要什么证书；再决定哪些 SKU 继续走邮政、哪些改走快递或 DDP 线路——输出「可直邮 / 需补资料 / 改快递 / 暂停发美」分数卡和补资料清单。

## 为什么现在

美国海关（CBP）10-14 宣布、10-22 在 Federal Register 发布终版规则：原定 10-22 生效的邮政入境新要求推迟到 **2027-01-20**。从那天起，凡是要交 **Section 201 / 232 / 301 关税**，或归 **FDA、CPSC 等机构管辖**的国际邮政包裹，必须通过 ACE 系统的新 **Entry Type 13** 电子申报才能走简易入境，否则就要走正式报关。Entry Type 13 要 10 位 HTSUS 编码、原产国、价值、税率和应缴关税、邮政追踪号、寄件人信息；只能由货主/买方或其指定的持牌报关行申报。

Etsy 已在社区公告提醒国际卖家：价值 2,500 美元以下的邮政包裹都要按新流程提交数据，受机构管辖的商品范围很广——食品、保健品、蜡烛、玩具、童装、部分首饰、含动物或植物材料（羽毛、贝壳、骨、皮革、木、软木、植物）的商品、涂抹在皮肤上的产品——**缺资料的包裹可能被扣或退回**；Etsy 让卖家连 Zonos 账户自查。快递（FedEx / UPS / DHL）本来就收这些数据，受影响的主要是走邮政的小卖家。1 月 20 日正好落在假日退换货和春节备货之间，现在梳理 SKU 来得及。

## 目标客户

从中国、英国、欧盟、加拿大、澳洲等地用邮政小包发美国的 Etsy 手作/复古卖家、Shopify 独立站直邮卖家、小型跨境卖家，尤其是卖蜡烛、护肤、首饰、童装玩具、含木/皮/贝壳/羽毛材料商品，或货源原产中国（带 301 关税）的店。已全部走快递或美国仓发货的卖家不是首要客户。

## 一人怎么起步

两周 concierge：先发一张公开自查表（「你用邮政发美国吗？商品原产国是哪？有没有 10 位 HTS 编码？是否含蜡烛/护肤/儿童用品/动植物材料？目前包裹谁申报？」），发到 Etsy 论坛国际卖家板块、r/EtsySellers、r/shopify、跨境卖家社群和 X 换 waitlist。给 5–10 个报名卖家导出商品清单，逐条标原产国、HTS 编码建议、是否带 301 关税、可能涉及的机构（FDA / CPSC / USDA / 鱼和野生动物局等）与常见证书（如儿童产品证书 CPC）；再按单量和货值比较「继续邮政 + 补资料」与「改快递 / DDP 线路」的成本，给出每个 SKU 的路线建议和 01-20 前的补资料时间表。先收一次性体检费，再做「跨境入境规则变更 + SKU 资料维护」月度订阅。

## 难度

中（主要是商品归类、机构管辖判断和物流成本比较；无需写代码，但 HTS 归类和机构要求容易出错，要回到官方原文核对）

## 变现路径

一次性 SKU 入境就绪体检（示意 $79–$249 / 店，按 SKU 数分档）；按 SKU 计价的 HTS 归类与资料整理（示意 $3–$10 / SKU）；之后做跨境入境规则与关税变更月报订阅（示意 $29–$99 / 月）。可与持牌报关行或 DDP 物流商做转介分成。可与 `s16`（EU 商品标识符）、`s17`（EU 处理费与关税）组成「跨境小包入境合规」系列，但条目分开。

## 注意的坑

你不是报关行：Entry Type 13 只能由货主/买方或持牌报关行申报，不要代客申报或承诺「保证清关」，只出资料清单和路线建议。HTS 归类的最终责任在卖家和报关方，给建议时注明「需报关行或官方裁定确认」。CBP 目前临时接受不带完整机构电子数据的 Entry Type 13，但结束时间会另行公告，别把这条当长期规则。CBP 还在推进把要求扩展到几乎所有国际邮件的低货值规则，内容会变，要盯 Federal Register。Etsy 公告里提到的 Zonos 是平台合作方的免费工具，你的价值在于逐 SKU 判断和成本比较，不是重复它。以 CBP 原文和 Federal Register 为准。
