## 一句话

帮 US TikTok Shop 卖家和自建 API 对接的卖家，把 BFCM 假日退货延长这件事落到账上和系统里：盘出 11-11 至 12-31 卖出、可以一直退到 **2027-02-10** 的订单量与金额，把退货准备金和 1–2 月现金流按这个窗口重算；查 ERP / 自研系统给出的退货二维码有效期是否已改到 2027-02-10 23:59:59 PT；再把 10 月新上线、默认开启的「高风险退款自动拒 / 转人工复核」设置看一遍，别让自动退款工具在假日里被薅。

## 为什么现在

TikTok Shop 官方 Seller University「Policy Pulse（October 2026）」（2026-11-05 更新）写明：

- **假日退货窗自动延长**：2026-11-11 16:00 PT 至 2026-12-31 23:59 PT 卖出的合格商品，可以一直退到 **2027-02-10**。这个延长自动生效，**优先于卖家自己设置的退货窗**；部分类目仍按标准规则，拍卖订单不适用。
- **API 对接卖家必须改逻辑**：返回的退货二维码有效期要覆盖到 2027-02-10 23:59:59 PT，否则买家售后申请会失败或被拒，并可能被处罚。BFCM 已于 11-11 开始，这部分订单已经在产生。
- **高风险退货/退款新控制**：一个开关自动拒绝被识别为高欺诈风险的退款，另一个把疑似滥用的申请从自动通过改为卖家复核（带「Review recommended」标签和倒计时）。两者**默认开启**，作用于「仅退款不退货」「自动同意退款」「自动同意退货」。卖家要知道它开着，也要按时处理转过来的复核单。
- 相关的既有规则：所有售后申请 4 个工作日审核窗，退货包裹投递后第 10 天起可审、第 30 天不处理自动通过，审核会影响售后处理时长（AHT）和无效拒绝率（ISRR）。

对小卖家的实际影响：11–12 月的销售额要到 2 月中才算「落袋」，1 月是退货高峰，结算和备货预算如果还按 30 天窗口算，会在年后吃亏；用 ERP 或自研脚本对接 API 的卖家多一个技术坑。

与 `s28`（账户健康分 BFCM 保护期）、`s39`（API 取消计入 SFCR）、`s41`（运费与重量结算）不同：本条只管 **BFCM 订单的售后窗口、退货准备金与 API 退货二维码**。

## 目标客户

US TikTok Shop 本土与跨境小卖家（尤其服装、饰品、3C 配件这类高退货类目）；用自研脚本或小众 ERP 对接 TikTok Shop API 的卖家；以及给这些卖家做代运营、财务记账的小团队。

## 一人怎么起步

两周 concierge：先发一张公开自查表（「你 11-11 后的订单退货窗按哪天算？退货准备金按几天留？ERP 给出的退货二维码几号过期？Abuse and fraud protections 里两个开关开着吗？谁每天处理 Review recommended 的单？」），发到 TikTok Shop 卖家社群、r/TikTokShop、X 和国内跨境群换 waitlist。对报名的 5–10 家：只读导出 11-11 起的订单与历史退货率，按类目估算 2027-02-10 前的退货金额，做一张「每周预计退货 × 现金流」表；对 API 卖家抽几单测退货二维码有效期；整理售后 SOP（复核单谁处理、4 个工作日内怎么回、哪些拒绝会算无效拒绝）。交付后延伸为 1–2 月每周退货与 ISRR 巡检的月费服务，可与 `s28` 打包成「TikTok Shop 假日健康包」。

## 难度

低–中（财务估算与 SOP 不难；API 部分要看卖家用什么系统）

## 变现路径

一次性体检（示意 $79–$199 / 店，含退货准备金测算与 SOP）；API 二维码有效期排查与小改（示意 $149–$399）；1–2 月每周售后巡检（示意 $49–$99 / 月）。

## 注意的坑

以 TikTok Shop Seller Center 与 Seller University 官方说明为准，哪些类目不适用延长要逐店确认，不要承诺「所有订单都到 2-10」。高风险退款开关是平台风控，不要教卖家关掉它来「提升转化」，也不要教规避退货的话术（会触发无效拒绝与 AHR 扣分）。只用卖家授权的只读权限，不索要账号密码或 API 密钥。价格只是示意，需自行验证。
