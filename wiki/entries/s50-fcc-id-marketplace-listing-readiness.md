# 美国站无线电子产品 FCC ID 就绪体检（10-13 已生效 × 缺 FCC ID 的 Listing 被拦 × 2027-06-01 卖点处须展示）

## 一句话

帮在 eBay US、Amazon US 等平台卖蓝牙、Wi-Fi、遥控、对讲机、智能家居等无线电子产品的中小卖家，把每个 SKU 的 FCC 授权一次对清：有 FCC ID 的，核对它和 FCC 数据库里的授权、实物标签、Listing 填的是不是同一个型号；走 SDoC（供应商符合性声明）的，确认有美国境内责任方；找不出授权的，及早下架或补认证，别等平台拦 Listing 或 2027 年展示规则落地才处理。

## 为什么现在

- **FCC 新规已生效**：联邦公报 FR Doc 2026-18535（FCC 26-50，2026-09-11 刊登）**2026-10-13 起生效**。新规明确在线平台推销未授权设备同样会被执法，不要求「明知」；还要求平台在线上卖点**展示设备的 FCC ID**。自营或经手货物的平台 **2027-03-01** 起执行，靠第三方卖家自证的平台 **2027-06-01** 起执行。新规范围只到大卖家（INFORM 法定义的 high-volume third-party seller）的全新设备，生效前发布且之后没改过的 Listing 也不算在内。同一份规则还禁止为含有 Covered List（FCC 涵盖清单）实体所产逻辑芯片/模块的设备授权。
- **eBay 已开始要**：eBay Seller Center「FCC ID」页说明，为配合 10-13 的平台责任条款，eBay 可能要求部分 Listing 补 FCC ID；被判为高风险的 Listing，二手或小卖家也可能在 2027-06 前被要求补。行业报道称，缺 FCC 信息的 Listing 可能无法创建、修改或重新上架，也可能对美国买家隐藏。
- **Amazon 早就按属性执法**：Amazon 帮助页列出 Wi-Fi、蓝牙、蜂窝、对讲机、信号放大器等须 FCC 授权的设备，以及「未认证」「SDoC 无美国责任方」等禁售情形；Listing 里的 FCC 射频合规属性填不对就会被移除。

一人能接的单：卖家手里常是供应商给的一份测试报告、一个看似 FCC ID 的型号串，或兄弟型号的 ID。逐个 SKU 去 FCC 数据库核对这件事很机械，但卖家自己不愿做，平台也不会帮他做。

与 `s38`（TikTok Shop 电子品类责任险）、`s36`（Amazon 安全类目责任险）不同：本条只管 **无线设备的 FCC 授权与 Listing 上的 FCC ID 是否对得上**。

## 目标客户

在 eBay US / Amazon US / Walmart / 独立站卖无线耳机、音箱、遥控玩具、智能插座、对讲机、GPS 定位器、无人机配件的中国跨境中小卖家与贸易商；帮这类卖家铺货的小代运营。

## 一人怎么起步

两周 concierge：先发一份公开自查表（「你卖的东西有没有蓝牙/Wi-Fi/遥控？每个型号有没有 FCC ID？这个 ID 在 FCC 数据库里查得到吗，查到的型号和你卖的是同一个吗？标签和包装上印了吗？」），发到 eBay / Amazon 卖家论坛、知无不言、跨境卖家群和 X 换 waitlist。对报名的 5–10 家：导出带无线功能的 SKU，用 FCC 设备授权检索（FCC ID Search）逐个核对授权方、型号、频段，标出「ID 写错 / 用了兄弟型号的 ID / 只有型号没有授权 / 查无授权 / 应走 SDoC 但缺美国责任方」五类；附实物标签照片要求和 Listing 应填字段，出一张「SKU × 问题 × 改法 × 是否要停售」表。延伸：新品上架前的 FCC 预审、供应商资料催收模板。

## 难度

低到中（核对靠 FCC 公开数据库和表格；判断 SDoC 与认证的边界需要读一点 FCC Part 15 说明）

## 变现路径

按 SKU 数打包的 FCC 核对（示意 $99 起 / 30 个 SKU）；新品上架前单品预审（示意 $15–$30 / SKU）；给代运营的批量核对表格模板或小工具订阅（示意 $29 / 月）。

## 注意的坑

不提供认证、也不代替实验室测试；查无授权的产品只建议停售或找有资质的实验室补认证，不要帮人「凑一个 ID」。FCC 规则和各平台的执行节奏以联邦公报、FCC 与平台官方页面为准，不承诺 Listing 一定能恢复。Covered List 相关产品可能根本不能在美国销售，遇到时直接提示风险。价格只是示意，需自行验证。
