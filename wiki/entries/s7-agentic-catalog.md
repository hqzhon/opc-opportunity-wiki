# Shopify Agentic Catalog 就绪体检

| 字段 | 内容 |
| --- | --- |
| 市场 | SaaS / 订阅 |
| 适配 | 偏技术 |
| 优先 | 是 |
| 更新 | 2026-10-27 |

## 一句话

帮 DTC / 独立站卖家检查并修复商品数据，使其能被 ChatGPT、Copilot、Gemini 等 AI 购物代理通过 Shopify Catalog 正确发现与展示——输出可修分数卡与持续漂移报警。

## 为什么现在

Shopify 已上线 Agentic storefronts 与 Catalog 资格/映射校验；商品要被代理发现，取决于标题属性完整度、变体分组、GTIN、可售区域等，而不仅是「店开着」。Stripe 在 NRF 2026 把 agentic commerce 列为零售主趋势。大量小店有货却 Catalog 不合格或映射错乱，报表缺口类似早期 SEO。AgentReady 等通识 App、以及 `s9`/`s11`/`s13`/`s15` 等专用楔子已出现——本条卡在**商品可发现性与 Catalog 资格**，不吞并政策探针或划线价专项。

## 目标客户

月销尚可、已上 Shopify、想吃 AI 渠道增量的 DTC 与跨境独立站（尤其美欧向）。

## 一人怎么起步

两周 concierge：落地页 + 免费「Catalog 就绪 Scorecard」（资格、标题/属性完整度、变体分组、GTIN、B2B-only 排除）→ 输出修复清单换 waitlist / 预付 → $29–$79/月持续监测与映射建议。先手工审计验证付费意愿，再做 Embedded App。

## 难度

中（需跟 Shopify Catalog / 销售渠道规则漂移；勿承诺「一定进某 AI 推荐位」）

## 变现路径

月订阅监测；一次性深度审计；后续可与 `s15` 划线价、`s9` 政策探针打包给代运营。

## 注意的坑

与通用 AEO（`s1` 搜索引用监测）不同，焦点是购物代理可购性与 Catalog 资格；与 `s15`（compare-at → list_price）不同，这里先解决「能否被发现」。Shopify 原生已提供部分能力，产品要卡在「诊断 + 批量修复 + 持续报警」而非再造 feed；B2B-only 商品会被排除，话术要分清。
